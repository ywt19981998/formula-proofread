# 字形与语义判定

## 三层证据

1. 语义：读定义与邻近公式，区分标量、矢量、矩阵、张量、集合、函数、算子、单位、标签、索引、行列变换记号。
2. 观察：原页实际正体/斜体、普通/粗体。字体名称只是证据之一。
3. 规范：记录用户指南条款及页码。未规定的习惯可单列建议，不能混作确认错误。

| 情形 | 处理 |
| --- | --- |
| 字体名无 Italic，但文字矩阵有剪切 | 可能是合成斜体，对照页面；整页旋转不等于斜体，检查两轴夹角而非单看 c/d。 |
| SymbolMT 无 Bold，render mode 2 且有描边 | 可能是合成加粗；结合笔画、描边宽度、颜色和透明度核对，不能直接判未加粗。 |
| 轮廓字或图片无字符数据 | 必须视觉复核；提取字母数不等于完整覆盖数。 |
| 私用区字符 PUA | 保留编码和字体，按当前字体映射或截图识别，不能跨 PDF 硬套映射。 |
| 大写 A | 可能是矩阵、代数余子式、集合、组名、点名，不能按大小写分类。 |
| A_ij 定义为代数余子式 | 是标量，不能因 A 大写而加粗。 |
| 行列式中写的是矩阵 A | 整体为标量，内部 A 仍指矩阵；若指南要求粗斜体，保留此属性。 |
| r_i、c_j | 可能是行列变换记号；未定义为向量时不强行加粗。 |
| 转置 T、微分 d、虚数 i、常数 e | 查当前体例与语境，不能把惯例说成指南明文。 |
| 希腊大写变量 | LaTeX 默认可能是正体；需要斜体时显式控制并验证。 |
| 整条公式加粗 | 可能是标题或强调；先区分层级样式与数学属性，不自动判所有标量错误。 |

主字母样式不能传播到全部上下标。数字、变量索引、描述词和分量标记分别判断。矩阵元素通常是标量，但依定义确认。单位、几何点、化学符号、统计量、随机变量等按学科和指南判断，不能套单一线性代数规则。

## 全覆盖台账

按页记录 PDF 页、印刷页、正文/公式/图示覆盖状态、未辨认区域 bbox、是否视觉审查、记录 ID。正确项可保留在工作底稿，不能进入错误清单。

脚本 named_bold、shear_candidate、stroke_bold_candidate 是线索。扫描完成不是审校完成。图片模糊时记录具体缺口并继续其他页，精准请求清晰材料；未解决区域不得计为正确或 complete。
